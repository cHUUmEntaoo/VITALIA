
# VITALIA

Sistema integral de gestión de citas médicas y atención hospitalaria.

## Descripción

VITALIA es un proyecto de ingeniería de software orientado a la gestión de citas médicas, administración hospitalaria y seguimiento de la atención de los pacientes.

## Roles del sistema

- Administrador
- Médico
- Recepcionista
- Paciente

## Tecnologías previstas

- Backend: ASP.NET Core 10 y C#
- Base de datos: Microsoft SQL Server
- Aplicación web: Next.js y TypeScript
- Aplicación móvil: React Native y Expo
- Control de versiones: Git
